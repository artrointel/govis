# Govis

사용자를 지속적으로 이해하고, 필요한 순간에 먼저 도움을 제안하며, 함께 목표를 이루어가는 개인 AI 비서를 만드는 프로젝트입니다.

프로젝트 이름은 **Govis(고비스)**입니다.

현재는 **프로젝트의 방향과 큰 틀의 동작 모델을 함께 정리하는 단계**입니다. 로컬 PC에 상주하는 서비스 프로세스를 비서의 실행 주체로 두고, 예약이나 사용자 응답 등을 계기로 원격 LLM을 호출하는 방향을 잡았습니다. 세부 설계와 기술 선택은 순차적으로 구체화합니다.

## 지향점

- 대화가 쌓일수록 사용자의 상황과 관심사, 목표를 이해합니다.
- 요청에 응답하는 것에서 나아가, 도움이 필요한 순간을 스스로 살핍니다.
- 사용자의 의사와 허용 범위에 따라 일을 수행하고 진행 상황을 전달합니다.
- 사용자가 자신의 데이터와 비서의 활동을 통제할 수 있도록 합니다.

활동 파이프라인은 **컨텍스트 인지 → 작업기억 → 목표 정의 → 작업계획 및 집행 → 능동제안 → 스케줄링** 순서로 구성합니다. 각 단계의 상세 문서는 전체 동작 모델에서 연결합니다.

독립적인 단·중·장기 루프를 두지 않고, 하나의 활동 루프에서 공통 맥락을 참조합니다. 기억은 기간 관점을 구분해 보관하되 판단할 때 함께 살핍니다. 질문에 대한 사용자 응답은 새 회차의 상황 변화로 받아들이고, 다음 기상 예약을 다시 결정합니다.

매 기상과 각 단계의 변화는 스냅샷으로 남겨 LLM·사용자·개발자가 시간 흐름을 따라 열람할 수 있게 합니다. 목표 종료 시에는 경과·결과·산출물을 정적인 보고서로 저장하여, 목표와 작업이 진행 중인 목록에서 정리된 뒤에도 기록을 확인할 수 있게 합니다.

## 진행 원칙

- 현재 문서와 논의는 한글을 기준으로 진행합니다. 영문화는 완성도가 높아진 뒤 검토합니다.
- 한 번에 많은 것을 확정하지 않고, 작은 주제부터 순차적으로 논의합니다.
- 제품의 목적과 사용자 경험을 먼저 정리하고, 구현과 기술 선택은 그다음에 다룹니다.
- 논의되지 않은 내용을 확정된 요구사항으로 취급하지 않습니다.
