# Govis — 프로젝트 방향과 목표

이 문서는 기존 대화에서 이어갈 제품 방향을 정리한 초기 초안입니다. 세부 내용은 함께 검토하며 다듬습니다.

프로젝트 이름은 **Govis(고비스)**입니다.

## 1. 만들고 싶은 것

사용자의 맥락을 지속적으로 이해하고, 일상과 장기적인 목표를 함께 챙기는 개인 AI 비서를 지향합니다.

사용자가 질문할 때 답하는 기능에 더해, 이전에 나눈 이야기와 현재 상황을 바탕으로 도움이 될 일을 발견하고 먼저 제안할 수 있어야 합니다. 사용자가 허용한 범위에서는 일을 진행하고 결과를 전달하는 역할까지 기대합니다.

J.A.R.V.I.S.와 같은 개인 비서는 장기적인 영감입니다. 그 이미지에 포함된 모든 능력을 초기 요구사항으로 삼지는 않습니다.

## 2. 해결하고 싶은 문제

- 사용자가 매번 자신의 배경과 상황을 다시 설명해야 합니다.
- 대화에서 나온 관심사와 목표가 실제 행동으로 이어지지 않고 잊히기 쉽습니다.
- 필요한 정보를 확인하거나 다음 행동을 정하는 일을 사용자가 계속 직접 챙겨야 합니다.
- 사용자가 먼저 요청하지 않으면 도움을 받을 기회가 생기지 않습니다.

이 문제들 중 무엇을 먼저 해결할지는 구체적인 사용 장면을 바탕으로 정합니다.

## 3. 제품 목표

### 사용자에 대한 이해의 연속성

사용자의 선호, 관심사, 진행 중인 일과 목표를 필요에 따라 기억하고 이후의 도움에 반영합니다. 기억은 사용자가 확인하고 수정하거나 지울 수 있어야 하며, 모든 대화를 영구 보관하는 것을 전제로 하지 않습니다.

### 적절한 선제적 도움

사용자가 매번 지시하지 않아도 도움이 될 기회를 발견하고 제안합니다. 동시에 지금은 말을 걸지 않는 편이 낫다는 판단도 할 수 있어야 합니다. 제안의 빈도보다 실제 유용성을 중시합니다.

### 목표를 향한 실행 지원

사용자가 원하는 일을 구체적인 행동으로 이어갈 수 있도록 돕습니다. 허용받은 일은 사용자가 계속 지켜보지 않아도 진행하고, 필요한 확인이나 진행 상황·결과를 전달합니다.

### 지속적인 비서 경험

시간이 지나거나 사용을 잠시 중단한 뒤에도 이전 맥락을 이어갈 수 있도록 합니다. 사용자가 필요할 때 자신의 비서에 접근하고 상황을 확인할 수 있는 경험을 지향합니다.

## 4. 지킬 원칙

- **사용자 주도권:** 비서의 판단보다 사용자의 의사와 선택이 우선합니다. 자율적으로 행동할 범위는 사용자가 통제할 수 있어야 합니다.
- **개인 데이터에 대한 통제:** 개인 정보와 기억을 사용자가 관리할 수 있어야 합니다. 정보가 외부로 전달되는 경우 이를 이해하고 선택할 수 있어야 합니다.
- **로컬 우선:** 사용자 PC에 상주하는 서비스 프로세스를 중심으로 비서를 운영합니다. LLM은 로컬에서 실행하지 않고 원격으로 호출합니다. 비서의 지속적인 활동과 작업공간은 로컬 환경을 중심으로 이어갑니다.
- **차분하고 신뢰할 수 있는 도움:** 과도한 알림과 반복적인 제안을 피하고, 무엇을 하고 있는지와 결과를 명확히 전달합니다.
- **열린 프로젝트:** 장기적으로 공개하고 다른 사람도 활용·개선할 수 있는 프로젝트를 지향합니다.

## 5. 기대하는 사용 장면

예를 들어 사용자가 대화 중 이직을 준비하고 싶다고 이야기합니다. 비서는 이를 곧바로 확정된 목표로 단정하지 않고, 사용자의 의도를 확인하며 이후 대화에 참고합니다.

적절한 시점에 준비 상황을 살피고, 지금 도움이 될 구체적인 다음 행동을 제안합니다. 사용자가 동의하면 관련 일을 돕고 결과를 전달합니다. 이미 상황이 바뀌었거나 제안이 불필요하다면 개입하지 않습니다.

이 장면은 제품 방향을 설명하기 위한 예시이며, 첫 기능이나 특정 사용 분야를 확정하는 것은 아닙니다.

## 6. 잘 만들어지고 있는지 판단할 기준

- 사용자가 배경과 상황을 반복해서 설명하는 부담이 줄어드는가?
- 먼저 건네는 제안이 사용자의 실제 필요와 맞는가?
- 대화가 사용자가 원하는 행동과 결과로 이어지는가?
- 비서의 개입과 활동 범위를 사용자가 이해하고 통제할 수 있는가?
- 시간이 지나도 이전 맥락을 이어가는 경험이 있는가?

측정 방법과 구체적인 목표치는 사용 장면을 정한 뒤 논의합니다.

## 7. 다음에 함께 정할 것

1. 가장 먼저 도움받고 싶은 상황과 현재의 불편함.
2. 그 상황에서 비서가 해주면 가치 있는 최소한의 역할.
3. 먼저 제안하거나 스스로 행동해도 되는 범위.
4. 기억했으면 하는 정보와 기억하지 않았으면 하는 정보.

큰 틀의 구현 방향은 [전체 동작 모델](전체-동작-모델.md)에 정리합니다. 로컬 PC의 상주 프로세스와 원격 LLM 호출을 기본 방향으로 삼되, 첫 개발 범위, 사용자 접점과 세부 기술은 아직 정하지 않습니다. 사용 장면과 추상 모델을 차근차근 구체화합니다.
