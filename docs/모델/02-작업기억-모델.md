# 작업기억 모델

## 1. 정의와 목적

LLM이 깨어날 때마다 이전 맥락을 이어받고, 사용자를 위해 진행하는 판단과 작업을 갱신하는 단계입니다. 동시에 그 결과를 담아두는 작업기억 공간을 관리합니다.

작업기억은 사용자 정보뿐 아니라 **비서가 어떤 방향으로 사용자를 돕고 있으며, 무엇을 진행했고, 무엇을 다시 살펴야 하는지**를 추적·기록·진단하는 공간입니다.

## 2. 입력

- 컨텍스트 인지 모델이 스테이징한 변화분.
- 이전 회차까지의 작업기억.
- 이전에 정한 활동 방향과 진행·보류 중인 작업.
- 이전 회차 이후의 실행 결과와 사용자 반응, 정정 사항.

## 3. 기억 내용 — 초기 구분

| 영역 | 담을 내용 |
| --- | --- |
| 사용자 맥락 | 현재 관련 있는 선호, 상황, 생활 패턴, 사용자 발언 |
| 작업 방향 | 어떤 도움을 주려 하는지와 그 판단의 근거 요약 |
| 진행 상태 | 이미 한 일, 진행 중인 일, 보류·중단된 일 |
| 미해결 사항 | 정보가 부족한 부분, 확인할 질문, 다시 점검할 가설 |
| 활동 진단 | 도움이 되었는지, 잘못 이해하거나 반복하고 있는지 |
| 연결 정보 | 관련 목표, 컨텍스트 출처, 다른 기간 관점의 관련 기억과 결과 |

이 구분은 기억의 역할을 설명하기 위한 초안입니다. 구체적인 문서·데이터 구조는 아직 정하지 않습니다.

기억은 공통 맥락을 바탕으로 단·중·장기 관점을 구분해 보관합니다. 오늘의 일정 예외, 최근 몇 주의 경향, 장기적인 목표를 한 상태로 뒤섞어 덮어쓰지 않습니다. 판단할 때에는 관련된 각 관점의 기억을 함께 참조합니다. 시간 범위가 여러 개인 정보의 연결 방식과 공통 사용자 정보의 보관 구조는 이후 정합니다.

## 4. 수행 내용

1. 변화분을 기존 기억과 대조합니다.
2. 수정할 필요가 있는 사용자 정보와 작업 상태를 판단합니다.
3. 새 내용의 추가, 기존 내용의 수정·유효성 변경 등 필요한 갱신을 수행합니다.
4. 기존 작업 방향이 현재도 타당한지 진단하고, 이어갈 일과 재검토할 일을 구분합니다.
5. 갱신된 기억과 남아 있는 불확실성을 목표 정의 모델로 전달합니다.

변화가 없거나 수정할 근거가 부족하면 기존 기억을 유지할 수 있습니다. 깨어났다는 이유만으로 내용을 다시 쓰지는 않습니다.

## 5. 출력

- 최신 맥락을 반영한 작업기억.
- 무엇을 바꾸었는지와 근거의 요약.
- 유지할 활동 방향과 다시 판단할 사항.
- 확인되지 않은 추론과 사용자 확인이 필요한 정보.

## 6. 다른 모델과의 경계

- 컨텍스트 스테이징은 이번에 발견한 변화분이고, 작업기억은 회차를 넘어 유지하는 상태입니다.
- 작업기억에 목표 관련 설명이 포함될 수 있으나 목표 정의와 갱신의 책임은 목표 정의 모델에 있습니다.
- 판단 기록은 결정과 근거 요약을 이어가기 위한 것입니다. 내부 추론 과정을 그대로 저장하는 명세는 아닙니다.
- 이후 모델이 실제 작업이나 사용자 전달을 수행하면 그 결과도 다음 회차의 기억에 이어져야 합니다.

활동 결과의 기억 반영은 공통 규칙입니다. 실제 작업 결과, 실패·보류, 변경한 목표, 사용자에게 한 질문과 제안, 아직 기다리는 답변, 다음 기상 결정 등을 남깁니다. 다음 기상에서 이전에 질문하거나 실행했다는 사실을 다시 추측하게 해서는 안 됩니다.

작업기억은 현재 판단에 필요한 상태이며, [활동 스냅샷](../활동-이력과-스냅샷.md)은 그 상태가 변해온 이력입니다. 기억을 갱신하거나 진행 중인 목표·작업을 정리할 때 과거 이력까지 덮어쓰지 않습니다. 종료 목표의 경과와 결과는 [보고서](../목표-종료-보고서.md)에서 참조할 수 있도록 연결합니다.

## 7. 예시

기존 기억에는 ‘사용자는 18시에 야외 운동을 하는 경향이 있다’는 정보가 있습니다. 새 대화에서 오늘 야근을 한다는 사실이 확인되면, 일반적인 운동 패턴은 유지하면서 오늘 일정에는 예외가 있다는 내용을 반영합니다.

비서가 운동 관련 날씨를 살펴보려던 상태라면 ‘오늘 운동 시간이 달라질 수 있으므로 재확인 필요’라는 후속 판단을 남길 수 있습니다. 한 번의 예외로 장기적인 습관 전체를 변경하지 않습니다.

## 8. 미정 사항

- 사용자 사실, 추론, 작업 상태를 어떻게 구분해 표현할지.
- 기억의 갱신 이력, 유효기간, 정리·삭제 기준.
- 사용자가 기억을 확인·정정할 수 있는 방식.
- 장기간 누적되는 기억의 분량과 회차별 참조 범위.
- 공통 사용자 정보와 단·중·장기별 기억의 구체적인 분류·연결 방식.
